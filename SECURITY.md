# Security policy

## Reporting a vulnerability

Please don't report security problems in public issues.
Report them privately through GitHub instead: on the repository's **Security** tab, choose **Report a vulnerability**, or use [this link](https://github.com/av-huette/avh-booking-system/security/advisories/new).

A helpful report says what is affected, how to reproduce the problem, and what an attacker could do with it.

## Supported versions

Security fixes are made for version 3, on its development branch `v3/main`.
